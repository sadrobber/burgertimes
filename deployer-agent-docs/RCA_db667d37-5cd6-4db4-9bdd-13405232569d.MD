# RCA — Run db667d37-5cd6-4db4-9bdd-13405232569d (burger-times-bsl)

## Symptom
Redeploy failed at step **build_image** (Cloud Build). The retry-wrapper text in the pipeline error is just the wrapping shell; the real failure is the frontend webpack compile.

## Actual error (build log, step #2 docker-build, frontend-build 13/14)
```
Failed to compile.
Module not found: Error: Can't resolve '@/components/admin/TabletCategoryGroupsCard.jsx' in '/app/src/pages/admin'
error Command failed with exit code 1.
```

## Root cause (reproduced in sandbox from this run's source)
The component file is stored with a **trailing space in its filename**, so the import path does not match the file on disk.

- Import in `frontend/src/pages/admin/SettingsAdmin.jsx:5`:
  ```js
  import TabletCategoryGroupsCard from "@/components/admin/TabletCategoryGroupsCard.jsx";
  ```
- Actual file on disk (verified via `ls -b` and a `for` loop):
  ```
  TabletCategoryGroupsCard.jsx\   ->  literal name is "TabletCategoryGroupsCard.jsx " (trailing space)
  ```
- Exact-name existence check:
  ```
  test -f '.../TabletCategoryGroupsCard.jsx'  ->  EXACT NAME MISSING
  ```

Webpack resolves the import to `TabletCategoryGroupsCard.jsx` (no trailing space), which does not exist, so the module cannot be resolved and the build fails. This is a source-level filename bug, not a manifest, tier, secret, or infra problem.

## Fix (Code — E1 must apply in the preview source, then redeploy)
Rename the file to remove the trailing space:
```
git mv "frontend/src/components/admin/TabletCategoryGroupsCard.jsx " \
       "frontend/src/components/admin/TabletCategoryGroupsCard.jsx"
```
(or recreate the file with the exact name `TabletCategoryGroupsCard.jsx`). No other file needs to change — the import path is already correct. After the rename, redeploy.

## Notes
- The deployer cannot fix this: renaming a source file requires a change in the preview repo (no write_file/source tool here, and the eph sandbox is throwaway and does not feed the build).
- The previous successful run (ab7b74a3-...) is still live at https://burger-times-bsl.emergent.host — production is unaffected.
